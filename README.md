# synergy-wallpapers

将本机 Wallpaper Engine 的视频 / 网页壁纸显示在 **Synergy 内部背景**，不操作 Windows 桌面壁纸。

## 宿主要求

0.2.0 及以上需要 Synergy 提供权限控制的同源媒体路由 `/plugin/resources/:scopeId/:pluginId/:generation/:operationId/:resource`。未包含该路由的原版 Synergy 3.0.22 不能只更新插件：先合入宿主修复并更新运行时。已包含修复的本机桌面版升级 0.3.0 只需更新插件，不必再次构建宿主。不要放宽全局 CSP，也不要把跨端口媒体或 blob 视频当成兼容方案。

## 安装和使用

1. 在支持同源媒体路由的宿主导入 `synergy-wallpapers-0.3.0.synergy-plugin.tgz`，确认包含 `ui.resources` 的权限，并在当前 Scope 启用。
2. 打开设置中的 Wallpaper 页面。自动发现 Steam 和壁纸库，无须手动选择目录。
3. 在缩略图网格搜索名称 / Workshop ID，按视频或网页筛选；点击即预览，列表保持展开。默认隐藏 scene 等不支持类型，每页 36 张，可加载更多。
4. 点击 **Synergy 的保存更改** 保留选择。关闭设置、重新加载界面后继续显示；取消或放弃草稿恢复保存的壁纸。
5. 关闭壁纸也是草稿操作，需要保存。插件禁用 / 卸载释放媒体和透明样式。播放失败显示原因与重试按钮，不将 iframe 的 load 事件当成播放成功。

配置按 Scope 保存，不绕过宿主保存 / 放弃语义，不修改主题配置。工作台、侧栏、顶栏及输入区采用分层融合，设置对话框保留 96% 遮挡度以便阅读。为避免宿主在 session / project 路由切换时重建 UI 组件导致壁纸短暂消失，最近一次已保存的壁纸设置会在当前 Scope 没有设置时作为本机 UI 回退；它只包含壁纸选择、显示参数和 Wallpaper Engine 扫描配置，不包含凭据或其他 Synergy 设置。显式保存 `selection: ""` 仍会关闭壁纸。

新包必须重新签名，不能沿用旧版签名；需要签名的来源通过原有发布者密钥对新包生成对应的 .sig。

## 界面融合（0.3.0+）

0.3.1 起移除了重复的声明式配置表单。插件详情页不再显示旧的英文/基础字段表；壁纸选择、扫描、预览和融合参数统一从 **设置 → Wallpaper** 的自定义界面操作。

在 **设置 → Wallpaper → 界面融合** 中选择清晰办公、均衡融合（默认）或沉浸壁纸。也可单独调整：

| 设置 | 默认 | 范围 / 行为 |
| --- | --- | --- |
| 跟随壁纸取色 | 开启 | 从预览图提取低比例底色；不改变文字、警告和按钮语义颜色 |
| 界面不透明度 | 76% | 40–96%；输入区额外增加遮挡，弹窗保持高遮挡 |
| 界面磨砂 | 16px | 0–24px；侧栏、顶栏、输入区背后的磨砂 |
| 背景遮罩 | 28% | 0–65%；跟随当前主题，深色压暗、浅色提亮 |
| 壁纸柔焦 | 0px | 0–8px；降低背景细节，0 保持原始清晰度 |

调整即时预览且不重新挂载视频；保存后刷新仍恢复，放弃草稿恢复此前数值。恢复默认融合只重置这五项，不改变壁纸、静音或 Synergy 主题。分页支持左右方向键和 Home / End，滑块支持键盘调整。

取色仅对 24×24 的缩略图采样，不逐帧读取视频；缓存最多 24 张，超时或缺图时使用中性色，切换/关闭时取消过期请求。关闭壁纸、播放失败或插件卸载会清理融合变量。低透明度偏好与系统强制颜色模式使用实色面板回退。

融合适配当前宿主工作台样式，并非自动生成完整主题；第三方插件自绘或硬编码底色不保证覆盖。复杂、明暗跳变强烈的壁纸建议使用清晰办公；不同壁纸和自定义主题的所有文字对比度没有逐一认证。磨砂也有 GPU 成本，低性能设备可以把界面磨砂和壁纸柔焦设为 0。

## 支持范围

- 视频使用浏览器 video 元素，编码支持取决于宿主浏览器运行时；默认静音，有声自动播放可能被拦截。
- 网页使用仅允许脚本的 opaque-origin iframe，注入 project.json 默认属性、基本静音音频回调和错误上报。不是完整 Wallpaper Engine 运行时，不提供真实音频采集、原生插件或硬件接口；专用 API、外部网络资源、部分框架初始化仍可能不兼容。CORSAIR Collection 的初始化错误会明确显示，不能当成已验证可用的壁纸。
- scene / scene.pkg 和未知类型无法渲染，不用缩略图冒充动态壁纸。可勾选显示不支持的壁纸查看它们，但不能选中。
- 媒体由插件的 IPv4 loopback 服务提供，经宿主同源路由流式转发。路径仍由插件校验，主页面 CSP 不变；HTML 保持沙箱隔离，不能访问宿主 DOM、凭据或任意宿主接口。远程部署不是本次验证范围。

## 开发与验证

需要 Bun 和 Node.js。plugin.json、运行时和 UI JS/CSS 由 plugin-kit 生成，不手改 dist。

```powershell
npm ci
bun run typecheck
bun run test
bun run build
bun run validate
bun run pack
```

浏览器夹具加载真实构建后的插件 UI、Synergy 工作台 CSS 和同源转发实现；主页面使用与真实宿主相同的严格 CSP，不连接真实插件设置：

```powershell
$env:SYNERGY_SOURCE = 'D:\Github\synergy'
bun run test:browser
```

打开输出地址，选择 Test video / Test wallpaper，验证保存后关闭设置仍有背景、刷新后恢复、关闭壁纸后 Discard settings 恢复、Toggle theme 切换配色、Disable plugin 恢复原样。sample.webm 是生成的两秒测试视频，不包含用户壁纸。此夹具不替代真实宿主集成验收。

真实验收必须在独立 SYNERGY_HOME 的宿主安装签名包，检查缩略图 naturalWidth、视频 readyState / videoWidth / currentTime 推进、保存 / 取消 / 刷新，以及旧 generation 和无权限路由拒绝。不要只检查 HTTP 200 或插件启动，不要重启用户正在使用的运行时。
